# 📝 TechnoJam 2026 – Task Manager

A full-stack Task Management Web Application built for the **TechnoJam 2026** hackathon/assignment.

The application allows users to create, view, update, delete, search, filter, and mark tasks as completed or pending.

---

## 🚀 Features

- ✅ Create new tasks
- 📋 View all tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- ↩️ Undo completed tasks
- 🔍 Search tasks
- ⏳ Filter pending tasks
- ✅ Filter completed tasks
- 📊 Display task count
- 💾 Store tasks permanently in MongoDB
- 📱 Responsive user interface
- 🎨 Clean and modern UI
- 💡 Motivational UI stickers
